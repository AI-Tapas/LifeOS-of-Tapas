# Local font assets

Unmodified Latin WOFF2 subsets of the existing Hanken Grotesk, Spectral and
Geist Mono families, served using `next/font/local`. These were recovered
from the application's existing Next.js Google Font download output; the
embedded copyright and OFL license metadata were inspected before copying.
The app no longer requires Google Fonts access during builds or page loads.
Other scripts use the existing system fallbacks.

Hanken Grotesk and Geist Mono retain their variable weights. Spectral includes
the original 400, 500 and 600 normal weights. See LICENSE.txt for the retained
copyright notices and SIL Open Font License 1.1.
